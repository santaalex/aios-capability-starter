# Capability Pack 与 Customer Pack

| 内容 | 归属 |
| --- | --- |
| 通用算法、通用规则、能力卡、输入输出、Skill | Capability Pack |
| 客户目录、命名、字段映射、模板、客户差异 | Customer Pack |
| CAD/机器人软件、许可证、厂商 DLL、本机入口 | Desktop / Adapter |
| 工程文件、任务结果、模型 API Key | 客户设备本地 |

不要为了不同客户复制 Capability Pack。客户差异由 Customer Pack 组合进去；同一通用
能力可以分配给多个客户和设备。
